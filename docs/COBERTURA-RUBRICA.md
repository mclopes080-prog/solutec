## Como testar (máquina do dono do repositório: Windows + XAMPP)

Pré-requisitos: MySQL do XAMPP rodando, banco e usuário criados conforme o README, e `backend/.env` preenchido a partir do `.env.example` (com `JWT_SECRET` de pelo menos 32 caracteres).

```powershell
npm install
npm run prisma:generate -w backend
npm run prisma:deploy -w backend      # aplica 20261102000000_sprint_1_usuario e 20261120000000_sprint_2_crud
npm run prisma:seed -w backend        # 4 categorias, 8 produtos, usuário demo + endereço
npm run typecheck
npm test
npm run build
npm run dev                           # API :3000 e Web :5173
```

### Teste de fumaça no navegador

1. Abra `http://localhost:5173/produtos`: os 8 produtos aparecem em cards com o placeholder.
2. Entre em `/login` com **`demo@solutec.test` / `Solutec@2026`**: o nome aparece no cabeçalho e o app abre `/app`.
3. Em `/app/pedidos/novo`, crie um pedido (endereço "Loja Centro" + 2 produtos). Mude o status para "Pago" e confira que os itens ficam somente leitura.
4. Em `/app/conta`, o e-mail aparece desabilitado. Altere o nome digitando a senha atual nos dois campos; o cabeçalho atualiza.
5. Clique em **Sair** e acesse `/app/produtos`: o app redireciona para `/login`.
